# 使用指南

## 空白首次启动

安装步骤见 [README](../README.md#快速开始)。第一次打开时，故事、角色、世界与聊天列表为空。你可以先配置模型，也可以先手工写下自己的素材；保存文字不会因此自动调用模型。

「设置 → AI 连接」中保存渠道、网关、密钥与模型。主模型负责角色回复，辅助模型用于导演、记忆等任务。模型目录不可用时可按服务商文档手填模型 ID。实际生成会调用该渠道并可能计费。

## 创建人物

进入「素材 → 角色」，新建人物，填写名字和「人物设定 · 自由正文」并保存。需要时展开结构字段，补充外貌、专长、性格、背景、开场与口吻示例；避免把同一正文反复填进多个字段。

「整理正文为字段」与「短多轮试聊」属于模型功能。整理先产生候选，确认采用后仍需保存。试聊最多六轮，用当前编辑草稿核对口吻，不创建故事或写入故事记忆。满意的回复可以先核对，再追加为口吻示例。

角色的「来源世界」用于归类；它不会自动把世界资料带入故事。创建故事时仍需明确选择世界与世界书。

需要头像或全身立绘时，可以自行上传图片，也可以在 Codex 打开本项目后，用角色编辑器的「复制给 Codex」调用 `$character-card-art`。这个可选功能使用 Codex 内置图像生成工具，仅以所选角色的外貌为依据，先生成可查看候选，再按你的采用或替换要求通过应用接口保存。已有图片不会因单纯生成候选而被覆写；详细规则见[角色插画技能](../.agents/skills/character-card-art/SKILL.md)。没有 Codex 时，普通应用功能和图片上传仍可使用。

## 保存世界原稿与世界书

新建世界，填写名字和原稿后保存。原稿可先留空；背景与生物档案、关联世界书也可以之后补充。

作者资料与故事资料有不同范围。原稿可设置为仅供作者留存；整理操作按你选定的本次资料读取。整理产生的候选需要逐项核对内容和来源，再决定是否采用、是否允许供故事使用。每批最多二十个词条，未完成部分可继续整理。

世界原稿页可选择新故事使用原文，或使用已确认的核心与世界书。用「检查实际上下文（不生成回复）」核对已保存内容的实际输入。已有故事保留自己的设定快照；素材更新不会自动覆盖旧路线，需要在故事中核对并采用设定更新。

## 开始故事与多人交谈

从新建故事入口选择人物、玩家身份、世界、世界书和开场。对话输入区提供回应风格、对象、代笔、内心与旁白；顶部还有继续故事、创作工具与更多操作。

| 回复方式 | 行为 |
| --- | --- |
| 并行 | 人物读取同一份生成前剧情，互相看不到本轮尚在生成的回复 |
| 串行 | 按所选顺序接话，后续人物读取已完成且可见的本轮回复 |
| 自由交谈 | 每次回复后重新安排接话者，名单是参与范围，不保证每人都发言 |
| 旁观交谈 | 选定人物与可选方向，让人物交谈一段，不伪造玩家台词或发送当前草稿 |

自由交谈可限制本段回复条数。暂停会等待当前回复保存；立即停止保留已完成回复；暂停并干预后可自行发言再继续。上游已收到的请求可能仍计费，本地停止不保证取消服务商收费。

消息操作中可复制、编辑、书签、查看上下文或记住事项。NPC 的局部重生成保留原候选；其他回复依赖已改变内容时，界面会提示「基于旧版本」。根据提示更新依赖或明确保留，不将旧候选当作新的事实。

普通聊天与故事编辑的影响不同。普通聊天改写历史会移除后续内容，保存前检查弹窗列出的范围；故事按当前路线与依赖关系处理，按实际确认提示决定。

## 草稿与失败恢复

人物、世界编辑页可在当前浏览器保留文字草稿；本地图片需要重新选择。草稿不是跨设备备份。模型生成候选还没有保存时，先核对任务状态与草稿，再使用刷新、重试或继续入口。

生成期间改过原稿时，过期候选不能当作当前结果直接覆盖。网络错误后先查看已保存内容，避免重复执行已经完成的付费操作。

## 分享与备份

素材库的「导出所选」先预览清单。所选角色/世界书分享包与私密迁移范围不同：分享包会排除私人创作原稿、故事和记忆，但你主动写进可分享正文的个人信息仍需自行核对。

完整世界导出、包含世界档案的场景包、私密迁移与整库备份可能含作者资料。将它们作为私人文件保管，不发到公开仓库或 Issue。默认整库工具排除保存的密钥与配对凭据，但对话与完整请求记录仍是私密资料。

重要创作建议定期备份。先正常停止服务，数据与备份都放在仓库外，再运行：

```powershell
.\.venv\Scripts\python.exe tools\maintenance\personal_library.py backup --source ..\data --target ..\backups\personal-library.zip
.\.venv\Scripts\python.exe tools\maintenance\personal_library.py verify --source ..\backups\personal-library.zip
```

离线工具不覆盖已有目标；恢复前请查看 `personal_library.py --help`，用新的外部数据目录核对结果。不要手工删 SQLite WAL/SHM 文件或只复制仍在写入的数据库主文件。
