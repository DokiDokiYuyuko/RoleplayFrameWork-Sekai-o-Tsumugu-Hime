# 核心特质专项提取

只整理原稿中明确属于该角色的能力、实力、技能、专长、职业手段和关键装备，写入 `traits`。这些内容必须描述角色实际能做什么、能达到什么效果，或怎样使用某件装备。根据原稿语境选择合适的 `traits_label`：奇幻设定可用“能力与实力”，现代题材可用“专业技能”或“专长与装备”，也可沿用原稿的小标题。不要默认角色具有超自然能力。

这是资料提取，不是短摘要。保留原稿明确列出的各项能力、等级、数值、作用范围、发动条件、使用限制、代价，以及与能力直接相关的弱点；不要把不同机制合并成泛泛的一句。

严格排除以下内容，即使原稿写得很详细也不能放入 `traits`：身份、经历、人物关系、外貌、性格、情绪、习惯、偏好、说话方式、欲望、剧情状态和普通行为描写。不要把“听话、害羞、爱抱怨、遇事沉默、依赖某人”等人格或行为特点包装成能力。普通角色只有在原稿明确写出职业技能、受训技能、知识专长或稳定的身体能力时才填写；不要把日常生活动作或群体性格当作技能。关键装备只记录装备名称和原稿明确的用途，不推测额外功能。

只使用原稿或主卡当前字段中的事实，禁止根据角色名、称号、物种或常见题材套路补齐。每项内容都必须能在原稿中找到明确依据；来源含糊时删去该项。没有符合上述范围的资料时返回空字符串。

仅输出一个 JSON 对象：`{"value":"完整的核心特质设定"}`。不要 Markdown、解释或额外字段。
